## 2. 关键结论与更正

- **K8s 1.38（官方 sneak peek，2026-11-23）**：运行时须通过 CRI `RuntimeConfig` 上报 cgroup 驱动，kubelet 不再接受 `cgroupDriver` 配置（除非开启 `LegacyCgroupDriverFallback`）；运行时须先于 kubelet 启动；kubeadm 不再默认设置 cgroupDriver，并在预检中报错。**`failCgroupV1: false` 在 1.38 仍可用**（短期保留，未来移除）→ 04 §2.3 中“1.38 起不提供”的说法要改为“kinstall 策略：legacy 模式随上游移除而下线”。其他：kubectl WebSocket opt-out 环境变量移除、kuberc 的 `name` 字段移除、准入 webhook 不再收到认证 / 鉴权类 review（KEP-5793）、Pod 级资源 GA、LimitedSwap 行为变化。
- **cri-dockerd v0.4.11 已实现 `RuntimeConfig` RPC**（源码 `core/docker_service.go`，按 Docker 的 cgroup driver 返回 systemd / cgroupfs；PR #222，0.3 回移 PR #425 于 2025-01-21 合并）→ R-RT-04 ✅；04 §5.3 / §15 与 ADR-015 改为“docker 运行时在 1.38 预期可用，GA 后实测转正”，不再因缺 RPC 标实验性。
- **Docker Engine**：29.0 起新装默认使用 containerd 镜像存储（升级安装仍为 overlay2）；**29.7.0 起提供实验性的内嵌 containerd（默认仍为独立进程）**——更正 04 中“29.8 起内嵌”的错误；当前最新 29.10.0（2026-11-16）。
- **Kubernetes Dashboard 已归档**（kubernetes-retired/dashboard；K8s 博客 2026-06-01 推荐迁移到 Headlamp）→ Web 控制台 Addon 改为 Headlamp（ADR-019）。
- **etcd（R-HA-03 / R-K8S-09）**：heartbeat 建议约为 0.5–1.5 × RTT（默认 100 ms），election timeout 默认 1000 ms、建议 ≥ 10 × RTT；磁盘要求 8 KB 顺序写 + fdatasync ≥ 50 IOPS 且 p99 < 10 ms，重负载 500 IOPS（约 2 ms）；高延迟跨城不建议拉伸 etcd，改为每地一套集群。
- **Helm 4（R-PLAT-04）**：install 默认 Server-Side Apply，upgrade 的 `auto` 沿用上次方式；使用 kstatus 等待资源就绪；插件支持 Wasm；Go SDK 包路径 `helm.sh/helm/v4/pkg/action`。
- **目标主机不依赖 Python**：EL8 / Alinux 3 默认源中没有 `python3` 元包（只有 platform-python / python3.x 模块流），kinstall 的 Facts 与 Task 只依赖 POSIX shell + coreutils，这一点优于 Ansible 方案。

## 5. 调优与加固要点

- **PostgreSQL（R-INIT-06）**：官方文档 18.4 推荐 Linux `vm.overcommit_memory=2`（配合 `vm.overcommit_ratio`）、大页（`huge_pages=try`，按 shared_buffers 计算 `vm.nr_hugepages`）、systemd `RemoveIPC=no`（否则用户注销会删除共享内存）；EDB 调优建议：read-ahead 4096 KB、SSD 用 `none` / `mq-deadline` 调度、脏页使用 `vm.dirty_background_bytes` / `vm.dirty_bytes`。
- **MySQL**：多 NUMA 节点开启 `innodb_numa_interleave`；关闭 THP；`vm.swappiness=1`。
- **等保 2.0 三级主机加固（R-INIT-08）**：来源为阿里云 Alibaba Cloud Linux 等保 2.0 三级版检查规则、ACK 等保加固说明和测评实践（口令 ≥ 8 位且含多类字符、90 天有效期、连续 5 次失败锁定；《网络安全法》要求日志留存 ≥ 6 个月）。检查项：空口令与 UID 唯一、pam_pwquality、口令周期与 `remember`、pam_faillock（Alinux 3 已无 pam_tally2）、TMOUT、SSH 仅 v2 / 禁 telnet / 限制 root 远程登录、umask 027、home 目录 750、su / sudo 限制、auditd 与 rsyslog 远程转发、关闭多余服务。**与 kinstall 的兼容点**：faillock 可能锁住执行账号（执行器失败重试需限流）、口令过期会中断自动化（执行账号单独策略）、TMOUT 影响长会话（执行器不走交互 shell）、umask 027 影响写出的文件权限（Task 显式 chmod）、`/tmp` noexec（使用 `/var/lib/kinstall/tmp`）。对应 03 新增 §9 harden 模块（ADR-018）。
