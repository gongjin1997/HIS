# kinstall 插件化基础设施安装平台 · 设计文档中心

> **定位**：用 Go 实现的插件化基础设施安装平台（暂定代号 kinstall，`CGO_ENABLED=0` 单二进制）。支持 **`host-binary`（二进制 + systemd）、`host-container`（Docker Engine 29 + Compose v5 + systemd）、`kubernetes`（开源 Operator + Helm v4）** 三元部署形态，跨 `amd64` / `arm64`（含 64K 页治理）与主流国际/信创操作系统；支持 **本地 / 在线 / 华为云 OBS·S3·OSS·COS 桶** 三元介质拉取；内置零外网 CDN 的 Vue 3 Web 控制台（`go:embed`）。覆盖 Kubernetes、Valkey/Redis、PostgreSQL、MySQL、OpenSearch/ELK + Kafka 4.x KRaft 日志全栈、SkyWalking 11.x APM、对象存储（SeaweedFS/Ceph/RustFS/Garage）以及 DevOps/RocketMQ/Seata/Milvus/Mongo/Neo4j/OnlyOffice/`generic-app` 全栈生态。
>
> **总控入口**：架构口径先读 **[`ARCHITECTURE.md`](./ARCHITECTURE.md)**（整体架构全景、28 包规范图与风险台账）；研发从 **[`DEV_TASK_CHECKLIST.md`](./DEV_TASK_CHECKLIST.md)**（126 项原子级研发任务打勾总表）、[00-系统设计总Checklist.md](./00-系统设计总Checklist.md)（132 项设计项、ADR-001～077）、**[DESIGN.md](./DESIGN.md)**（前端 UI 样式与组件唯一视觉基准）、[WEB_DESIGN.md](./WEB_DESIGN.md)（控制台 IA 与前端工程规范）与 [deep-design/G1](./deep-design/G1-平台-服务层高可用审批审计与Go后端完整代码方案.md)（24 表可执行 DDL + 全仓 Go 1.27 后端代码方案）开始。

> **当前包：`v4.5-complete`（2026-11-26，全三阶段封板 + `ARCHITECTURE.md` v1.1 + `DESIGN.md` v2.0 + 全仓 45 篇系统架构 / 安全供应链 / 插件 / 测试全域深度一致性终审修复）**。`spec/gen_os_docs.py --check` 通过（退出码 0）。
